## Зачем это нужно

Java статически типизирована: тип каждой переменной известен при компиляции. От типа зависит, сколько памяти занимает значение, какие операции допустимы и как ведут себя вычисления.

## Суть

Типы делятся на два вида:

| | Примитивы | Ссылочные типы |
|---|-----------|----------------|
| Что хранится | само значение | ссылка на объект в куче |
| Может быть `null` | нет | да |
| Примеры | `int`, `double`, `boolean` | `String`, `Integer`, массивы, ваши классы |
| Сравнение через `==` | сравнивает значения | сравнивает ссылки |

Восемь примитивов:

| Тип | Размер | Заметка |
|-----|--------|---------|
| `byte` | 8 бит | от −128 до 127 |
| `short` | 16 бит | |
| `int` | 32 бита | тип целых литералов по умолчанию |
| `long` | 64 бита | литерал с суффиксом `L` |
| `float` | 32 бита | литерал с суффиксом `f` |
| `double` | 64 бита | тип дробных литералов по умолчанию |
| `char` | 16 бит | беззнаковая кодовая единица UTF-16 |
| `boolean` | не определён спецификацией | `true` / `false` |

## Пример

```java
int max = Integer.MAX_VALUE;
System.out.println(max + 1);              // -2147483648: переполнение без ошибки
System.out.println(Math.addExact(max, 1)); // ArithmeticException

System.out.println((byte) 130);           // -126: старшие биты отброшены

System.out.println(0.1 + 0.2 == 0.3);     // false
```

## Как это устроено внутри

- Целочисленное переполнение «заворачивается» по модулю 2ⁿ (дополнительный код).
- `double` хранит число в двоичной форме IEEE 754. Многие десятичные дроби (0.1, 0.2) в ней не представимы точно, поэтому для денег используют `BigDecimal`.
- Приведение `int` → `byte` просто берёт младшие 8 бит. Это сужающее преобразование, его нужно писать явно.
- `Integer a = 127, b = 127;` даёт `a == b` истину из-за кэша значений от −128 до 127, а для 128 уже нет. Поэтому объекты-обёртки сравниваем через `equals`.
- Java всегда передаёт аргументы **по значению**. Для объектов копируется значение ссылки, поэтому метод может изменить состояние объекта, но не подменить переменную вызывающего.

## Типичные ошибки

- Сравнивать `double` через `==`. Правильно: разница меньше эпсилон.
- Не замечать переполнение `int` при суммах и факториалах.
- Сравнивать `String` и `Integer` через `==`.
- Делить целые и ожидать дробный результат: `1 / 2 == 0`.
